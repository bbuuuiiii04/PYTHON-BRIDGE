• # Spectral cue catalog

  The strongest design is simple: family+tier guarantees the visual language; spectral analysis animates that language from inside. WALL stays a wall, HOUSE stays groove-led,
  COMET stays directional, and NEUTRAL stays restrained—no spectral spike gets to swap identities mid-drop.

  Two current facts must be fixed before this catalog can be promised live:

  - The live config now has distinct family×tier pools, but the picker still treats them as fail-open preferences, not guarantees (config/led_look_director.json:581,
    led_dispatch_policy.py:2022).

  - Laser scene policy receives phrase/transport state, not spectral envelopes. The existing native-pack path can continuously overwrite CH8/CH9, while CH11 remains authored/
    pass-through (laser_models.py:122, soundswitch_laser_player.py:124).

  ## Measurement ground

  I measured the current v4 cache read-only:

  - 1,306 valid schema-v4 entries, 472 MB, 678,110 beat rows.
  - All entries contain the 21 per-beat fields, seven quarter-beat bands, and frame-rate growl_band_frames.
  - growl_centroid_frames exists on 1,295/1,306 entries: 99.16%.
  - sustained_synth_flags fires on 35.82% of beats and thick_flags on 83.08%, so neither is selective enough to trigger a cue alone.
  - Useful corpus anchors: growl_band_frames median 24.6/p90 32.1 dB; sustain_mid_db median 16.3/p90 21.9 dB; sustain_high_db median 2.2/p90 10.5 dB; attack_low_db median 5.0/p90
    17.8 dB.

  The exact stored fields are defined in audio_spectral_features.py:78; current derived texture, build, centroid-motion, and section measures live in spectral_profile.py:208.

  Labels:

  - MEASURED-GROUNDABLE: today’s fields can express the driver. Visual thresholds still need operator calibration.
  - SPECULATIVE: the mapping lacks enough ear labels, or a named P2 field is required.

  All normalization below means the same library-wide formula—not per-track cue hacks:

  Nsection(x) = clamp((x − section p20) / (section p90 − section p20), 0, 1).

  Sparkles and strobes always use wall-clock time. Beat measurements may change their density, width, or brightness, but never restart the sparkle field or become the strobe
  clock.

  ## WALL — pressure and strobe escalation

  ### 1. Pressure Door — T1 — MEASURED-GROUNDABLE

  CONCEPT
  Two solid color slabs squeeze inward, making the room feel physically narrower.
  A restrained time-based flicker keeps even WALL T1 unmistakably heavier than HOUSE or COMET.
  DRIVING SIGNAL → Trigger: current DropDecision.family == WALL && tier == 1, derived from drop_window_vector. Compression depth: Nsection(series.full_db). Flicker duty:
  Nsection(series.growl_flatness) gated by series.growl_band_db.
  WHERE IT LIVES → f2.drop_look_routing.WALL["1"], banks.default.drop; paired pressure-release look in post_drop.
  FEASIBILITY → new renderer; needs the family/tier hard guarantee.

  ### 2. Sawtooth Barrage — T2 — MEASURED-GROUNDABLE

  CONCEPT
  Jagged blocks fire left-right across the strips like teeth closing around the room.
  The strobe remains time-based, while the music decides how many teeth are visible per flash.
  DRIVING SIGNAL → Segment count from series.onset_density_midhigh; bite strength from series.fluxsum_midhigh; landing shove from series.attack_low_db.
  WHERE IT LIVES → f2.drop_look_routing.WALL["2"], drop role; a calmer segmented drift in post_drop.
  FEASIBILITY → new renderer plus in-memory spectral modulation.

  ### 3. Sustained Siege — T3 — MEASURED-GROUNDABLE

  CONCEPT
  The first impact lights the room, but the wall never relaxes between kicks.
  It stays dense and hostile for tracks whose power is continuous rather than arrival-based.
  DRIVING SIGNAL → run(growl_flags && thick_flags) plus persistent series.full_db, series.growl_band_db, and scalars.growl_timbre_p90; attack_low_db controls only the opening
  hit. This directly addresses the REWIND/SIGNAL continuous-wall failure described in the docs/research/operator_track_labels_2026_07_09.md:495.
  WHERE IT LIVES → WALL["3"], sustained drop sections and later chorus re-fires.
  FEASIBILITY → needs refactor axes separating intrinsic hardness from arrival impact; existing two-color strobe renderer can be reused.

  ### 4. Black-Iron Cathedral — T3 — MEASURED-GROUNDABLE

  CONCEPT
  Tall alternating panes of the two palette colors rise and collapse like violent stained glass.
  Fast timbre movement makes the panes shear sideways without changing the palette.
  DRIVING SIGNAL → Pane height from Nsection(series.full_db); shear speed from growl_centroid_movement_measure() over growl_centroid_frames; strobe duty from growl level, with a
  tier-set safety ceiling.
  WHERE IT LIVES → WALL["3"], only during measured growl-motion spans.
  FEASIBILITY → new renderer plus centroid-envelope delivery; no new extraction.

  ## Laser choreography

  All laser concepts obey one shared contract:

  - Spectral data selects an authored MIDI scene or updates the existing held CH8/CH9 pack overlay. It does not spray raw MIDI messages every analysis frame.
  - Existing emergency and blackout masks win. The four-beat pre-chorus mask always forces darkness and restores afterward.
  - NEUTRAL→small remains laser-silent.
  - When lasers fire, LEDs receive a bounded brightness dip, never a kill. Existing true blackout owners can still darken them.
  - CH11 remains authored/pass-through. WALL may select an already-authored strobe scene; no new general CH11 writer is implied.
  - Scripted SoundSwitch tracks remain untouched.

  There is one honest conflict: the operator label says Utopia’s final NEUTRAL T2 drop warrants lasers, while the ratified NEUTRAL→small rule silences it (docs/research/
  sol_spectral_review_2026_07_09.md:108). This catalog does not violate the newer law. Utopia gets lasers only if family/tier truth changes or that policy is explicitly revised
  later; sustain alone is not a secret override.
