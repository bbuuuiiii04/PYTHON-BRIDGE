# Prompts Live In The Repo

Session prompts authored into `$HOME` become invisible strays.
Seventeen such prompts were found on 2026-07-03.
Author prompts under `docs/prompts/` when they should persist, or under a
declared scratch directory when they should not.
Never use `$HOME` as the durable handoff surface.
Evidence: 2026-07-03 phase-4 audit.
