# Registry Rows Are Indexes

Registry cells are pointers, not feature history.
Keep rows to a few lines and link the authority spec or roadmap.
Feature history belongs in the spec's phase table or completion record.
AWR-113 had grown into a full changelog before the truth pass compressed it
back into an index row.
Evidence: `61c7d2b`.
