Strip layout

Drag corners on the room. Double-click (desktop) or long-press (touch) an edge to add a point, a corner to remove one. LED spacing is fixed — the path is never stretched.

Add corner places a new bend in the middle of the selected edge (or the longest edge if none is selected). Remove corner needs a selected corner and keeps at least two corners.
