# Support Policy

This project is not a supported product. It is my early-alpha personal bridge for my local DJ lighting setup.

## Current support scope

The only known working scope is my current local setup. Anything else is unvalidated unless listed in `docs/status/support_matrix.md` and backed by validation evidence.

## Not currently supported

- broad Rekordbox version support
- Windows support
- Linux support
- arbitrary SoundSwitch installations
- arbitrary laser fixtures
- arbitrary Govee devices
- plug-and-play setup for other users
- production or show-readiness guarantees

## Reporting useful validation

Use `.github/ISSUE_TEMPLATE/hardware_validation_report.yml` for hardware evidence and `.github/ISSUE_TEMPLATE/compatibility_report.yml` for version/device/OS compatibility evidence.
